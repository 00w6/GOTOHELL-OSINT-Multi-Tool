# GOTOHELL OSINT Multi-Tool 🛡️

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![License](https://img.shields.io/badge/License-Proprietary-red)

A powerful, colorful, and encrypted Python OSINT Multi-Tool featuring 15 legal networking utilities for cybersecurity researchers and ethical hackers.

## ✨ Features
- **[1-5]** IP Lookup, Domain Resolver, Phone Info, Email Breach Check, Username Search.
- **[6-10]** DNS Lookup, HTTP Headers, Subdomain Scanner, Port Scanner, Discord ID Lookup.
- **[11-15]** WHOIS Lookup, MAC Vendor, Hash Generator, SSL Checker, CVE Search.
