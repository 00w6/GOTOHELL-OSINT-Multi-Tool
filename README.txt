3. FEATURES (10 TOOLS)
--------------------------------------------------
Once the tool opens, you will see a colored menu with 10 options.
Type the number of the tool you want to use and press Enter.

[1] IP Lookup - Find the location, ISP, and Google Maps link of any public IP.
[2] Domain Resolver - Find the IP address of any website.
[3] Phone Number Info - Find the carrier, location, and timezone of a phone number (must include country code, e.g., +336...).
[4] Email Breach Check - Check if an email was leaked in a data breach.
[5] Username Search (OSINT) - Search for a username across GitHub, Instagram, Reddit, etc.
[6] DNS Records Lookup - Find A, MX, TXT, and NS records of a domain.
[7] HTTP Header Grabber - See the backend servers of any website.
[8] Subdomain Scanner - Find hidden subdomains (e.g., mail.google.com).
[9] Port Scanner - Check which common ports are open on a server.
[10] Discord ID Lookup - Get public profile data, avatar, and creation date of a Discord ID.

Press [0] to Exit the tool.
